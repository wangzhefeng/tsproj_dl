## 原设计 §12.1：设计澄清与偏差


| 项目 | 内容 | 性质 |
| --- | --- | --- |
| 模型命名 | 从讨论暂名 SpatialLatentAR 统一为 GSLAformer，拟议模型文件与实验类同步命名 | 本次文档命名决定 |
| 空间读出 | 用 `[CLS]` 补足原图未定义的实体序列到分组向量转换 | 实现建议，不是图示事实 |
| 静态分组 | 静态条件沿用，不强制每步预测 | 语义细化 |
| 训练稳定性 | 使用冻结空间编码器的两阶段方案 | 工程选择，需实验评价代价 |

以下追加 R2 决策，保留上表初稿记录而不将旧建议伪装为当前要求：

| ID | 用户选择或工程细化 | 对原方案的影响 |
| --- | --- | --- |
| D1 | 用户：先完成模型和功能测试，真实数据验收暂不启动 | 移除首轮真实数据门槛，不移除未来业务验证 |
| D2 | 用户：新增机房或测点不重新训练，也要能预测 | 移除实体 ID embedding／按实体 scaler；可变实体轴，冷启动标记 |
| D3 | 用户：支持通用未来信息接口，有可靠数据再启用 | 明确目标时刻条件融合、已知信息 mask 与版本校验 |
| D4 | 用户：接受未超过对照，必须如实报告 | 工程完成与业务采用分开，不设强制胜出门槛 |
| D5 | 用户：加入，提供归属表并让关系参与计算 | 原首版不加跨层级交互的限制失效；在池化前加关系注意力 |
| E1 | 工程：多步负荷预训练，阶段 B 固定完整表示链 | 替代一步预训练，减少短视表示风险；不保证 latent 足够预测 |
| E2 | 工程：定义条件化动态 latent，不承诺严格解耦 | 修正“预测 latent 不含静态信息”的潜在过强解读 |
| E3 | 工程：latent 标准差仅加权损失 | 固定回灌坐标，避免重复归一化 |
| E4 | 工程：课程仅最终阶段早停，完整保存恢复状态 | 避免尚未学远期就被全 horizon 验证提前终止 |

E 项是为落实用户边界而提出的可执行工程决定，不冒充用户逐项指定的参数。合成配置不代表真实业务参数。

R3 在用户授权优化文档后追加以下修正，R2 决策记录只作历史解释，不覆盖当前正文：

| ID | 修正 | 原因与代价 |
| --- | --- | --- |
| R3-01 | 池化前共享实体因果 GRU，ID 保留跨时对齐 | 修复逐帧集合表示丢轨迹；增加实体时序计算与 teacher memory 管理 |
| R3-02 | 部分信息 teacher + 分组软质量，取消全系统完整门槛 | 防止辅助标签随规模消失；质量是启发式，仍须噪声／缺失实验 |
| R3-03 | 连续有界方差权重，单组常量保留 | 消除阈值百万倍跳变；lambda 与权重仍非最优性保证 |
| R3-04 | direct/A/AR 共用完整已知未来路径，lead 按原点 | 消除信息集不公平；新增条件编码模块，已知未来不加错误因果限制 |
| R3-05 | 历史逐时刻属性／关系版本 | 避免换父级后必须等 L 稳定窗口；增加 as-of 版本选择测试 |
| R3-06 | 周期 smoke 与 M1–M5 分开 | 防止仅复制日周期就通过机制验收；增加定向小任务而非真实业务训练 |
| R3-07 | 关系消息／全部关系消融分开，mode 产物矩阵 | 清理旁路归因、单步梯度和统一产物清单错误 |
| R3-08 | horizon-macro 选优、origin-only latent 统计、资源限额 | 修正名称与 reduction、重叠加权及规模承诺 |

R4 根据用户本轮 AIDC 需求追加以下明确修订，不回改 D1–D5 与 R3 的历史事实：

| ID | 修订 | 原因与代价 |
| --- | --- | --- |
| R4-01 | 应用范围明确为跨 AIDC 总负荷，新增站点留出模拟验收 | 原三层示意不足以定义通用输入；新增多站点数据与评估职责 |
| R4-02 | 六组对象目录、资产／测点／特征与目标计量边界分离 | 容纳不同点位粒度，避免多级功率重复求和 |
| R4-03 | schema 3：typed src/dst、逐类型约束、多关系偏置、站点合同 | R3 全局归属 DAG 不足以表达供电／冷却／任务关系；暂无旧产物迁移 |
| R4-04 | base、M1–M5、多 AIDC 三层模拟证据 | 典型机制组合不能确保生产泛化；增加生成 oracle 与反事实 |
| R4-05 | 小时至三天独立 profile，容量上限与生产全量节点分开 | 原 H=6 smoke 不覆盖业务 horizon；增加长递推资源实测 |
| R4-06 | 按源码分级复用，保留主入口并隔离数据／实验合同 | 防止误用固定列 embedding、非因果卷积、旧 checkpoint 与 scaler 回退 |
| R4-07 | 原图映射、新图和结构化 I/O 联动归档 | 图示为拟议计算路径，不包装成已运行架构 |
