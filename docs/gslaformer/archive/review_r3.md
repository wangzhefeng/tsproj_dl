### 3.1 R1：正确性与复用

| 攻击问题 | 核查与结果 |

| 同一空间集合能否对应不同未来？ | 能。M1 给出 8/9 反例；R3 在池化前保留共享实体历史，ID 用于对齐而非参数查表 |

### 3.2 R2：质量与文档一致性

- design 定义语义，implementation 固定 tensor、阶段与配置，mechanism_tests 定义可证伪任务；入口相互链接。
- schema_version 同步为 2；未来路径、实体 memory、历史关系版本都有消费者，不保留“存了但不用”的接口承诺。
- 新增 episode_collection 后补足 split_mode；不把 base 的时间索引分区用于短 episode。
- valid_macro_mse 与 horizon-macro reduction 统一；micro 指标单独命名，禁止平均 batch metric 冒充 split metric。
- 按 mode／variant 定义产物，direct、total_only、naive 不再被要求生成不属于它们的 latent／阶段文件。
- 小集拟合门槛承认未校准，加入绝对误差下限处理，不要求本已近零的模型继续按比例下降。
- 任务、预算、配置均是实施目标；没有将文档检查写成模型已实现。

### 3.3 R3：效率与扩展

- 一次请求真实历史只编码一次；未来路径只编码一次；B 中保留该图梯度，不逐 horizon 重复做历史／计划编码。
- 不跨 origin 复用计划或 teacher 状态，避免以缓存优化引入 as-of 错误。
- 稠密关系 mask 不宣称稀疏复杂度，增加节点、时间长度与单张量分配限额；上调限额需要实测，不能截断实体。
- 机制任务采用有针对性的运行矩阵，不默认任务×所有变体全乘积。
- 同 epoch 不等于同算力，要求报告实际 update、forward 次数、参数和耗时；本轮没有性能数据。

### 3.4 R4：架构层次与科学承诺

- 保留用户 D1–D5，没有以第一性原理为由删掉已要求的关系建模、新实体能力或 latent 回灌。
- 原图、R2、R3 区分清楚：GRU 与完整未来路径是 R3 的明确扩展，不假称原图本来如此。
- latent 定位为带质量条件的预测表示，不宣称充分状态、因果图或物理守恒。
- no_relation_message 与 no_relation_all 拆分；后者还清除度数和质量权重中的关系旁路。
- 周期 smoke、机制可学习性、未见组合结果与真实业务验证分开；研究可能得到负面结果，不以强制胜出来判功能完成。
- 数据／训练保持独立实验契约，未顺手改造原有主线；根指令文件审批边界得到遵守。

## 6. 未消除的 P2 风险

### 6.1 表示与闭环风险

共享 GRU 只解除已证明的信息折叠，不保证固定宽度保存一切相关信息。冻结表示仍可能偏向历史总负荷或静态条件；MSE 预测的平均 latent 可能偏离编码器典型状态。需要机制拟合、回灌诊断和真实数据验证，文档不能给出精度保证。

### 6.2 质量权重风险

q 是可执行启发式，不是置信概率；相关缺失、整组掉线与观测过程变化可能偏置辅助目标。方差权重有界不等于最优，lambda=0.1 未经调参验证。首轮必须报告有效率和 loss 量级，不能自动调参数隐藏退化。

### 6.3 预算与容量风险

1000 update 的小集标准、epoch 上限和 MPS 容差尚未在完整模型上校准。限额只避免已知过大分配，不保证完整反向传播不 OOM。失败需要实证归因并记录修订，不能只改阈值变绿。

### 6.4 泛化与物理边界

新实体免重训指类型／特征 schema 不变下的结构兼容，冷启动真实精度未知。mean/sum/count 不是守恒约束，也不保证随节点数量单调。未来已知结构变化仍不支持，需要明确报错。

### 6.5 审查独立性与执行前置

本轮是单上下文四视角审查，存在同源盲点；它不等价独立多代理复核。模型代码不存在，无法验证全部梯度、数据加载和 checkpoint 实现。本轮 AGENTS 正式登记未写入，不能借用并行任务的登记冒充本轮完成。

### 6.6 P1：并行新增资料尚未与本版规格统一

`architecture.json:5` 使用“跨 AIDC”标题，`:17` 的关系范围包含供电、计量、归属、冷却、任务部署；当前 R3 文本仍承诺同 schema 同系统新增实体，关系首版为有向无环归属表，并不承诺跨系统泛化或上述全部关系语义。标题本身不能证明错误，但必须明确跨站是训练范围、应用范围还是零样本能力，并核对各关系的方向、约束和测试。

该文件在收尾期间由并行工作新增，尚未完成与本轮文档的统一、渲染检查和稳定快照复审。最小处理是先冻结该任务输出，再统一需求边界、图示和契约；不要让两个会话继续互相覆盖。此项阻止宣称“当前目录全量审查通过”，但不撤销本轮数值探针和文本修订的局部证据。
