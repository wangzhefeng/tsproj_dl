# GSLAformer 文档目录

**GSLAformer**：**Grouped Spatial Latent Autoregressive Transformer**，中文名为**分组空间隐状态自回归 Transformer**。

这是本项目针对 v4.0 架构图采用的工作名称，不代表已经发表的模型，也不宣称名称在公开文献中唯一或架构具备已验证的原创性。

## 文档入口

- [模型设计与开发方案](design.md)：R4 架构语义、保留的用户决策、范围与修订记录。
- [AIDC 输入输出与业务对象](input_output.md)：完整设备／点位目录、类型关系、总负荷边界、结构化张量与输出。
- [架构图资料目录](architecture/README.md)：集中保存原图、图源、图示与证据；[模块说明](architecture/architecture.md)、[交互图](architecture/architecture.html)、[图源](architecture/architecture.json)。
- [开发实施规格](implementation.md)：张量／文件契约、关系注意力、新实体推理、条件融合、两阶段状态机、完整功能配置、拟议命令与验收任务。
- [多 AIDC 模拟数据与验收](synthetic_aidc.md)：任务—电力—暖通联合生成、站点留出、缺测与小时至天级矩阵。
- [已有组件复用与框架接入](integration.md)：源码核实、可复用边界、数据／配置／训练／结果链路。
- [AIDC 完整配置设计样例](aidc_profile.example.json)：schema 3、六组、一天预测；不是当前入口可执行配置。
- [机制型合成验收](mechanism_tests.md)：M1–M5 的确定性生成规则、成对反例、运行矩阵与能力边界。
- [R3 对抗审查](review_r3.md)：四视角审查、数值探针、修复记录和剩余风险；不代表模型训练通过。
- [原始架构图](architecture/v4.0.png)：本方案的图示依据，现与其他架构图资料集中保存，图像内容不变。

## 当前状态

当前为 R4 文档设计，尚未实现或训练 GSLAformer。本次授权为 AIDC 文档完善、组件与框架核查及重绘架构图，不授权模型开发、项目依赖变更或正式实验运行。根 AGENTS 的 DOC-003 跟踪本次文档任务；历史 R3 审查的证据与限界原样保留。

用户已确定的首版范围：

- 先完成模型与功能测试，真实数据验收暂不启动。
- 面向不同 AIDC 的总电力负荷，六组输入覆盖算力、IT 电力、配电、暖通、空间与环境；设备数量、点位粒度和合法连接可不同。
- 同一 schema 下新增实体和未见站点使用冻结权重预测；联合多站训练与站点留出进入模拟验收，但不保证冷启动或真实零样本精度。
- 归属／供电／计量／冷却／任务等 typed relations 在实体汇总前参与计算；多层功率不重复累加。
- 支持通用未来协变量接口，有可靠起点可见数据时启用。
- 不要求超过对照模型，但必须如实报告。

推荐先读 `input_output.md` 和 `architecture/architecture.md` 理解业务与数据流，再读 `design.md`、`implementation.md`；开发接入看 `integration.md`，模拟验收同时看 `mechanism_tests.md` 和 `synthetic_aidc.md`。拟议代码文件、训练命令与 synthetic 指标门槛均没有模型运行结果。

R4 保留 R3 的实体历史、部分观测质量、完整未来路径和双头回灌，补齐跨 AIDC 数据合同与验收；不因“模拟训练”就宣称能够确保生产泛化。小时至三天是独立 profile 的验收目标，当前稠密注意力的参考容量也不代表生产全量服务器可直接运行。

## 目录约定

- 本目录存放设计文档、设计样例及验证记录；全部架构图相关资产集中到 `architecture/`，包括原始 `v4.0.png` 和绘图证据。图示证据不存生产数据，后续正式模型实验记录须明确真实执行依据。
- `design.md` 是当前设计入口，`implementation.md` 是执行契约；两者冲突须修正并记录，不能静默选择。根目录 `AGENTS.md` 仍是项目治理与任务登记的权威来源。
- 后续设计变化应追加决策或偏差记录，不静默修改历史实施结论。
- 实施进度只有在附上实际验证命令、结果和产物后，才能标记为 `Done`。
- 正式训练与预测产物进入项目 `results/`，不放入本目录。
- 文件、接口和模块名称在设计阶段均为拟议项，不表示代码已经存在。
